## 2. Motor Puro de Truco Paulista TDD

### Scope Técnico
- Vira (NÃO é manilha) → Manilhas: Copas > Espadas > Ouros > Copas > Ouros > Espadas > Copas
- Definição das 4 cartas imediatamente superiores a cada carta (conforme ADR)
- Hierarquia de naipes e força relativas codificadas
- Rodada completa com 3 jogadores + AI: repartição, apertos, tores, levadas
- Empates simples (mesma pontuação ou valor total da mão)
- Mão de 11 cartas (ferro para o banco)
- Escada local: 1 → 3 → 6 → 9 → 12 (exclusiva do motor TDD)

### Estrutura do Código
```
packages/truco-core/
  src/
    types.ts          # Card, Suit, TrumpLogic, HandEvaluation
    trick.ts          # ResolveTrick(), highestPlayer()
    round.ts          # FullRound flow com AI
    engine.ts         # Game state machine
  tests/
    trick.test.ts     # TDD unitários para vira, hierarquia, rodadas
    hand.test.ts      # Mão de 11, empates, escada
```

### Artefatos
- `packages/truco-core/src/engine.ts`
- `packages/truco-core/tests/round.test.ts`
- `docs/specs/truco-paulista-rules.md`

### Testes e Critério de Aceite
```bash
pnpm -F truco-core test
# Esperado: todas as suites verdes (vira, manilha, hierarquia, escada, empate)
```

## 3. Lobby / Salas e Servidor Autoritativo em Tempo Real (2 jogadores)

### Escopo
- Sem autenticação: sala anônima por `roomSlug`
- Socket.IO server-authoritative envia estado após repartição e cada ação
- Privacidade absoluta da mão do oponente (client nunca recebe hand completo)
- Ambiente local ou container dev (não mobile)

### Conectores de transporte
```typescript
const io = require('socket.io')(server, { cors: { origin: '*' } });
io.on('connection', (socket) => {
  socket.on('joinRoom', ({ room }) => {
    socket.join(room);
    broadcastState(socket.id, gameState); // estado completo sincronizado à todos
  });
});
```

### Artefatos de serviço em dev
- `apps/backend/src/server.ts` (Socket.IO server com rooms)
- `apps/backend/tests/e2e/lobby.test.ts`
- `docker-compose.dev.yml` (local containers: backend+frontend)

## 6. Reconexão e Sincronização

### Estratégia de Reconnect
1. Client perde conexão → buffer actions locais offline
2. Ao reconectar, server envia snapshot atual via `gameState`
3. Client reconcilia diff entre local e servidor

### Artefato de resilioência
- `apps/frontend/src/hooks/useReconnection.ts`
