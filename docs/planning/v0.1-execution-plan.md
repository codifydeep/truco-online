## 2. Contratos Formais

### 2.1 Contrato Backend-Product (tdd-regression-guard)

**Responsável:** `backend_data`  
**Artefato:** `src/rules/truco/puntos.ts` + testes TDD  
**Critério de Aceite:**
- Teste que falha sem lógica de pontuação correta
- Implementação mínima verde
- Refatoração sem mudança de comportamento observable
- PR contra `release/v0.1` com CI verde
- Revisor: `quality_security`

### 2.2 Contrato Frontend-Grafismo (requesting-code-review)

**Responsável:** `frontend`  
**Artefato:** `src/game/state.ts` + gráficos Three.js (R3F)  
**Critério de Aceite:**
- Componentes renderizam com estados v0.1 (lobby/partida/final)
- Transições validadas manualmente e em CI
- PR contra `release/v0.1` com evidências visuais
- Revisor: `cto`

### 2.3 Contrato DevOps-Docker (local-homologation)

**Responsável:** `devops`  
**Artefato:** `docker-compose.yml` no projeto `truco-online-dev`  
**Critério de Aceite:**
- Contêineres com labels corretos (`com.codifydeep.project=truco-online`, etc.)
- Health check /ready em `/health`
- Build e deploy verdes
- Limpeza com `--remove-orphans` ao finish

### 2.4 Contrato QA/SecOps (regression)

**Responsável:** `quality_security`  
**Artefato:** Suíte de testes E2E + segurança OWASP  
**Critério de Aceite:**
- Smoke tests passantes após deploy
- Regressão zero contra regras corrigidas
- Validação sem benchmarks inventados
- Revisão independente do PR implementável
